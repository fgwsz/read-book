# 📖 read-book — 命令行专注阅读器

`read-book` 是一款专为**沉浸式阅读**设计的命令行工具。它摒弃了繁杂的界面，每次只展示**一个自然段**，让你在终端中远离干扰，专注于文字本身。同时，它支持超大文本文件（GB 级），并提供了书签、笔记等辅助功能，是程序员、写作者和深度阅读者的理想伴侣。

## ✨ 核心设计理念

- 🎯 **专注阅读**：界面极简，每次只显示**一个段落**，没有滚动条、没有多余信息，让你心无旁骛。
- 📖 **自动折行**：根据终端宽度自动换行，且**不断开单词**，保证阅读流畅。
- 🔖 **智能分段**：将文件中的每个非空行视为一个自然段，符合大多数文本格式。

## 🚀 功能特性

### 阅读体验
- **段落式阅读**：每次只展示一段，按 `↑`/`↓` 切换，节奏由你掌控。
- **超大文件支持**：仅索引段落偏移，按需读取，内存占用恒定，轻松打开数 GB 的日志或小说。
- **自动进度记录**：退出时自动保存当前段落，下次打开快速续读。

### 书签与笔记
- **书签管理**：为关键情节添加**带标签**的书签（如“主角觉醒”），可随时查看、编辑或删除。
- **段落笔记**：为任意段落添加带时间戳的笔记，支持编辑、删除，笔记会在段落下方预览。
- **详情查看**：按 `i` 查看当前段落的完整书签标签和所有笔记内容。

### 纯键盘交互
- 所有操作通过键盘完成，无需鼠标。
- 子窗口（书签列表、笔记管理）操作后保持打开，直到你主动退出，流程连贯。

### 跨平台与零依赖
- 完美支持 Windows (CMD/PowerShell)、Linux、macOS 终端。
- 仅使用 Python 标准库，无需安装任何第三方包。

## ⌨️ 快捷键一览

| 按键        | 功能说明                                   |
|-------------|--------------------------------------------|
| `↑` / `↓`   | 上一段 / 下一段                            |
| `g`         | 跳转到指定段落（输入数字）                 |
| `b`         | 打开书签列表（可跳转、编辑、删除）         |
| `m`         | 为当前段落添加带标签的书签                 |
| `n`         | 为当前段落添加笔记                         |
| `N`         | 切换笔记显示/隐藏                          |
| `l`         | 打开当前段落的笔记管理（可编辑/删除）      |
| `i`         | 查看当前段落的书签标签和所有笔记完整内容   |
| `q` / `ESC` | 退出程序（自动添加书签）                   |

**在书签列表或笔记管理中**：
- `↑` / `↓`：选择条目
- `Enter`：跳转（书签列表）或查看（笔记管理）
- `e`：编辑当前选中项（标签或内容）
- `d`：删除当前选中项
- `ESC`：返回上层

## 🚀 快速开始

### 环境要求
- Python 3.6 或更高版本

### 下载与运行
```bash
# 克隆或下载项目
git clone https://github.com/yourname/read-book.git
cd read-book

# 运行阅读器
python read-book.py 你的小说.txt
```

### 首次使用
- 程序会在当前目录下自动创建 `.read-book-data.json` 存储书签和笔记。
- 退出时自动记录当前段落，下次打开可通过 `b` 查看书签列表并跳转。

## 🗂️ 数据存储

所有书签和笔记保存在程序所在目录下的 `.read-book-data.json` 文件中。  
格式示例：
```json
{
  "/path/to/your/file.txt": {
    "bookmarks": [
      {"idx": 10, "timestamp": "2025-01-01T12:00:00", "label": "精彩章节"}
    ],
    "notes": {
      "10": [
        {"timestamp": "2025-01-01T12:05:00", "content": "主角做出关键选择"}
      ]
    }
  }
}
```

## 🧱 技术架构

项目采用清晰的分层架构，保证代码的可维护性和扩展性：

```
read-book/
├── 工具层        平台抽象（Windows/Unix）、按键映射、控制台辅助
├── 核心层        领域模型（Bookmark / Note）、仓储接口
├── 实现层        JSON 持久化、文件索引与段落读取
├── 业务层        阅读服务、书签服务、笔记服务
├── 表现层        视图渲染器（仅负责显示） + 命令处理器（控制交互流程）
└── 主控制器      依赖组装、主循环、命令路由
```

**设计亮点**：
- 命令处理器模式：每个用户操作独立为一个类，新增功能无需修改现有代码。
- 依赖注入：所有依赖通过构造函数传递，便于测试和替换。
- 视图与业务逻辑完全解耦，理论上可快速移植到图形界面。
